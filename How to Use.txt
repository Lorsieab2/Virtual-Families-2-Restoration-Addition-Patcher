Virtual Families 2 Restoration/Addition Patcher - How to Use
============================================================

ELI5 version:
This patcher makes a separate modded copy of your official Virtual Families 2
folder. It checks that your original game folder looks correct before it
changes anything.

Check for updates:
https://github.com/Lorsieab2/Virtual-Families-2-Restoration-Addition-Patcher/

1. Download and install the official Virtual Families 2 PC version.

2. Unzip this patcher package. Somewhere near the top of a drive is best (for
   example C:\Games or your Downloads folder): Windows cannot open files whose
   full path is longer than 260 characters.

3. Run:
   Launch_GUI.bat

   The BAT file is the supported launcher. It resolves files relative to the
   folder where you extracted this ZIP. The patcher's own files are in the
   "Virtual Families 2 Fun Patcher Files" folder beside it; keep that folder
   next to the BAT files. You never need to open it.

4. The patcher should auto-load manifest.json (from that folder).

5. Select your vanilla Virtual Families 2 install folder. It should be the
   folder that contains Virtual Families 2.exe, Images, Sounds, Assets, and the
   required DLL files.

6. Review the optional patch checkboxes.

   Two store settings, both on by default:
   - All 36 Flea Market goods: the Flea Market lists all 36 of its goods all
     the time, always in stock (the Towelette, Anti-spam Software and
     Rockhound Certificate too: buy them again and again). Untick it for the
     original game's Flea Market: 5 goods, picked again after 6 hours of
     real time.
   - R Refreshes the Store (a cheat): in the store, press R on the Clothing
     and Hairstyles page to pick the six outfits again (hairstyles stay;
     outfits you already bought keep their looks). On the Flea Market page R
     picks 5 new goods, but only while All 36 Flea Market goods is unticked.
     R does nothing anywhere else, and nothing while a box is open.

   Time Controls (on by default) adds a Time Controls button to the game's
   Settings screen: pause, resume, Slow, Normal, Fast, 5x and 10x, and a Time
   Warp of +3 years for everyone at home. The Time Warp costs the same as the
   store's own Time Warp ($2,000, read from the game's store when you click
   it). If your family cannot afford it, you are told so and nothing changes.
   With Free and Guaranteed Cheats ticked it is free.

   Fix Vanilla Game Bugs (on by default) also stops a crash of the original
   game: at every start the game asks LDW's server to log in (login.php), and
   the server now sends back about 3 KB of text, more than the game has room
   for, so the game closed by itself about 20 seconds after it started. That
   answer is now read safely and ignored, as if the server had not answered.

7. Optional but recommended: click Dry Run (Validate Only).
   Dry Run validates that the patcher's working. It does not actually
   change/write files.

8. Click Enable/Disable Patches. If you uncheck a patch later, click this
   button again to rebuild the modded folder from vanilla with that patch
   disabled.

9. The patcher creates or refreshes a separate modded folder next to your
   vanilla game folder. Your original game folder and original saves are left
   alone.

10. Run the clearly named modded EXE inside the new modded folder.

Tools tab:
The patcher window has two tabs. Patches is where you choose and apply patches.
Tools holds Back Up Saves, Restore Saves, Copy Player Slot, Rename Family and Game Speed for your
Virtual Families 2 families (they live in Documents/LDW/<game folder name>), Game
Mechanics, the Family Tree Maker, the Picture Maker, and a How to Use guide for
every button. Small ? buttons beside controls open the page for that control.
Back Up Saves copies the save folder, including the patcher's own files in
"Virtual Families 2 Patcher Data", into its Backups folder (the game is paused
for the copy if it is running). Game speed is set to Paused in the backup's
family saves (your own saves are unchanged), so a restored backup opens paused
and never catches up on the time since it was made. Restore Saves shows
exactly what will change, asks first, and backs up your current saves before
it restores anything.
Copy Player Slot copies a family into an empty save slot of the same save
folder under a new name, with everything the patcher keeps for it (the game's
previous save, Up to 28 Children, outfit pictures, the Family History log and
the Family Tree Maker's tree file). Quit the game first; it asks before it
copies, never writes a slot in use, and backs up your saves first as
"Backup <date> (before copy)".Rename Family changes the name a family slot is shown under. Virtual Families 2
has no family surname: a slot is shown under the player name typed when it was
started. Quit the game first; the new name can have up to 19 characters (the
game keeps no more), and your saves are backed up first as
"Backup <date> (before rename)".
Game Speed pauses or unpauses a family in its save. Quit the game first, pick
the family (each shows its speed now) and choose Paused or Normal. Paused works
as if you paused just before the game last saved; Normal as if you unpaused it
right now, so the time it spent paused never counts. Your saves are backed up
first as "Backup <date> (before speed change)".
Game Mechanics shows how the game works underneath: ageing, needs, illness, old
age, babies, careers, money, leaving home, dating, Random Events (Email and Popup Events), weather,
messes, collectibles and the store, with every chance and timer in real time.
Each line is marked VERIFIED-E (the game's own code was run and counted),
VERIFIED-C (read from the game's own code) or UNCONFIRMED. It only shows text
and changes nothing, so the game may be running.
Picture Maker draws your family members exactly as the game draws them and
saves them as PNG pictures with a clear background. Pick the game folder (the
pictures come from it; nothing of the game ships with the patcher). From my
save: choose the save folder and the family. Everyone at home can be drawn in
the house (any body frame and head turn, with or without the shadow, a mother
with the babies she is expecting), on the Details screen, on an event screen or
in the Family Tree; family members who left home or died, and earlier
generations, only in the Family Tree, as the game does. The outfits in the tool
tray are listed with their own pictures. Make your own: pick the sex, age, head
(hairstyle), outfit and how it is drawn; children are drawn smaller and heads
turn old at 45, as in the game. A patched game shows the patcher's Holiday
outfits; untick Patched look for the original game's look. Save PNG saves at
the game's size, 2x or 4x (crisp) or your own size (smooth), with a small clear
margin unless you untick it. Your saves and game folders are only read.

Crash capture QA only (optional):
The patcher never changes Windows Error Reporting settings or launches the
game. If a test build crashes, copy crash-capture-manifest.template.json to a
new file and fill in the absolute path, byte size, and SHA-256 of the exact
modded EXE. Run vf2_crash_capture.py verify-exe first, then use its
emit-wer-plan command to generate separate reviewable setup and restore scripts.
They are inert until you choose to run them manually: run setup, reproduce and
capture the crash, and then run restore. After a crash,
record the dump/log sizes and hashes in the separate capture manifest, run
validate-bundle, and only then emit the IDA JSON. Never substitute manifest.json
for this exact-build crash manifest.

Existing saves:
Vanilla Virtual Families 2 saves are compatible with the modded version!
The modded game uses its own save folder under Documents/LDW using the modded
EXE name. To play existing saves in the modded game, copy the contents of your
original Documents/LDW/Virtual Families 2 save folder into the modded save
folder shown after patching. When you move saves between modded folders, copy
the "Virtual Families 2 Patcher Data" folder beside them too: it holds the
patcher's small per-save files (for example the pictures of the outfits in your
tray, kept by Fix Vanilla Game Bugs). Without it the saves still load, and the
tray's outfits show what the original game shows.

If no valid install is detected:
Make sure you selected the official Virtual Families 2 install folder, not a
partial folder or the patcher folder itself.
